Questions fréquentes

Les réponses avant de commencer.

La banque validera les modalités précises, les canaux disponibles et les délais affichés avant l'ouverture du service.

Comment déposer une réclamation ?

Le portail proposera un formulaire avec le motif, les faits et les pièces utiles. Un agent pourra aussi enregistrer une demande reçue par un canal autorisé par BSCA.

Comment retrouver mon dossier ?

Une référence unique sera communiquée à la réception. Le suivi réel nécessitera une vérification d'identité.

Quel est le délai de réponse ?

Les délais affichés dans l'application seront ceux validés par la conformité et les procédures de BSCA Bank.

Mes informations sont-elles visibles par tous ?

La version finale limitera les données aux profils habilités et séparera les notes internes des messages destinés au client.
